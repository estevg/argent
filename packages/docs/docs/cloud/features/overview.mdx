This page is the conceptual overview of Argent Cloud. Each feature gets its own page as the product opens.

## Hosted devices

Argent Cloud runs the simulators and emulators in a hosted environment. The agent drives a hosted device with the same interaction model that [Argent Toolkit](/docs/features/interacting-with-apps) uses on a local device.

## Sessions without a developer

A hosted session runs on a schedule or from a pipeline. The session records the same evidence as a local session: screenshots, recordings and flow results.

The [reference](/docs/cloud/reference/overview) contains the technical details.
