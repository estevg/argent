Argent Cloud is the hosted product line of Argent. Argent Cloud runs the devices and the agent sessions on Software Mansion infrastructure instead of your machine. Argent Cloud is in preparation, and this documentation grows as the product opens.

## What Argent Cloud is

[Argent Toolkit](/docs/fundamentals/getting-started) gives your AI assistant access to the simulators, emulators and devices on your own computer. Argent Cloud moves that work to a hosted environment. Your assistant connects to the hosted devices in the same way, and your computer does not run the simulators.

## Who Argent Cloud is for

Argent Cloud is for teams that want the same agentic testing without a local device setup on every machine, and for pipelines that run agent sessions without a developer at the keyboard.
